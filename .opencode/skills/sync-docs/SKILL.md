# Skill: Sync Docs

## Description
This skill outlines the procedure to keep the project documentation up-to-date with the codebase.

## Steps
1. **Analyze Changes**: Check recent commits and file changes.
2. **Update MODULES.md**: If `Project.swift` changed, update module dependencies.
3. **Update REQUIREMENTS.md**: Mark completed features as checked. Add new requests to Backlog.
4. **Update ARCHITECTURE.md**: If new patterns are introduced, document them.
